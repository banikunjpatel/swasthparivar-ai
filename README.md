# swasthparivar-ai
AI-powered personalized Indian family nutrition and wellness app based on Ayurveda

**Key Features:**
Personalized Meal Generator: AI generates 7-day Indian meal plans per member based on dietary needs (diabetes, hypertension, etc.) and Ayurvedic dosha (prakriti).
Ayurveda-Infused Wellness Sync: Suggests family-aligned routines like yoga sessions, detox days, and recipe balancing for dosha harmony.
Budget & Season Smart Menus: Plans optimize for seasonal, local ingredients and suggest low-cost alternatives like millets.
Family Profile System: Allows creation of multiple user health + wellness profiles under one family account.
Smart Grocery & Health Tips: Creates AI-based grocery lists, shows food nutrition via image input, and delivers daily wellness tips.
 
**Technology Stack:**
AI/ML Tools: OpenAI GPT-4, Scikit-learn, YOLOv8 (for image food recognition)
Frameworks/APIs: Angular, Python FastAPI, Firebase, Hugging Face
Datasets: Indian food nutrition DBs, Ayurvedic prakriti assessment data, Seasonal produce calendars, Public health datasets (ICMR/NIN)
